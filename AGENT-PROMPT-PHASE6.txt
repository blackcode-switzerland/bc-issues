## THE FAILURE MODE THIS PHASE HAS

Phase 3 failed loudly. Phase 4 failed quietly. Phase 5 failed later.
Phase 6 fails SLOWLY — a projection that drifts.

entities is derived data. If a write path forgets to upsert, nothing breaks
today: search returns slightly stale results, activity misses an entry, and
nobody notices for weeks. By then you cannot tell which rows are wrong.

So:
  - every entities write is in the SAME TRANSACTION as its source write; a test
    must prove a rolled-back source write leaves no entities row
  - the reconciliation job ships in this phase, not later
  - verification asserts entities COUNTS MATCH source counts per type, not that
    queries return something
